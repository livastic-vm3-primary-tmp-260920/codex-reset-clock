FAQ

자주 묻는 질문

1. 내 Codex 사용량은 언제 초기화되나요?

Codex 또는 ChatGPT의 설정 → 사용량에서 정확한 초기화 시각을 확인하고 입력하세요. 이 독립적인 계산기는 계정에 로그인하거나 사용량을 가져오지 않습니다. 5시간·주간 한도 적용 여부도 요금제마다 다를 수 있습니다.

2. 이 사이트에서 Codex를 강제로 초기화하거나 전역 초기화를 예측하나요?

아니요. 계정 사용량을 초기화하거나 숨겨진 잔여량을 읽거나 임의로 정해지는 전역 초기화를 예측하지 않습니다. OpenAI의 공식 발표 또는 실제 사용량 화면으로만 확인할 수 있습니다.

3. 저장된 초기화권을 사용하면 주간 초기화 시각도 바뀌나요?

대상에 포함된 한도를 갱신하고 주간 초기화 기준이 바뀔 수 있습니다. 적용 조건·만료일·갱신되는 항목은 실제 계정 혜택과 공식 초기화 안내를 확인하세요.

4. 계산기와 계정에 표시된 시간이 다르면요?

이 사이트는 직접 입력한 시각과 기기 시계로 계산합니다. 유료·보관 초기화권 사용, 워크스페이스 설정이나 시간대 변경에 따라 공식 시간이 달라질 수 있습니다. 계정의 사용량 화면이 우선합니다.

5. API 키·계정·입력한 날짜를 수집하나요?

계정이나 API 연결이 없습니다. 계산은 브라우저 안에서 처리됩니다. 선택적으로 로컬 저장을 켠 경우만 해당 브라우저에 날짜를 저장하고 '모두 지우기'로 삭제할 수 있습니다. 웹파일 제공을 위해 GitHub Pages 서버에서 일반적인 HTTP 연결 정보가 처리될 수 있습니다.

6. 돈 내는 즉시 초기화와 저장된 초기화권은 같은가요?

다릅니다. 대상 계정의 유료 즉시 초기화는 결제가 승인되면 바로 적용되는 반면, 보관된 초기화권은 제공 조건에 따라 나중에 직접 사용할 수 있습니다. 공식 유료 초기화 안내 ↗

독립적인 무료 도구로 OpenAI가 운영·후원·보증하지 않습니다. 광고, 추적, 외부 스크립트, 회원가입이 없습니다. 공식 문서 확인일: 2026년 10월 28일. 정책은 변경될 수 있습니다.
